# Périodique

Le tableau périodique des 118 éléments, en pixel art, avec un quiz.

*English version: [README.en.md](README.en.md)*

## Commandes

- **Survole** une case : son nom et sa masse s’affichent. **Clic** : sa fiche.
- **Flèches** : passer d’un élément à l’autre · **Q** : quiz · **Échap** : tout réafficher.
- Clique une **famille** dans la légende pour l’isoler ; reclique pour tout revoir.
- **Chercher** : un nom (fer), un symbole (Au) ou un numéro (79).
- **Manette** : la croix ou le stick déplace, **A** répond au quiz, **Y** lance un quiz.

## La fiche

Numéro, symbole, nom, masse atomique, famille, état à 20 °C, période, groupe et radioactivité.

## Le quiz

Un nom d’élément s’affiche : clique sa case (les symboles sont cachés). Dix questions, d’abord surtout les éléments les plus connus. Ta meilleure série est gardée.

## Données et synchronisation

Les records du quiz sont enregistrés par NeoDex, sauvegardés et synchronisés entre tes PC si la synchro est activée.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Périodique → Installer**.
